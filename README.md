# CodeTrack 🚀

CodeTrack is a Java-based coding problem tracker that helps users manage, search, and track coding problems.

## Features

- Add coding problems
- View all problems
- Search problems
- Mark problems as solved
- Track solving progress

## Technologies Used

- Java
- OOP
- Collections
- HashMap
- ArrayList

## Example

The project stores details such as:

- Problem Name
- Platform
- Difficulty
- Topic
- Solved Status
